README - تشغيل خادم استقبال طلبات التوظيف

ماذا يفعل هذا:
- يضيف خادم Node بسيط يستقبل النموذج من `apply.html` عبر `POST /submit`.
- يدعم رفع ملف السيرة (`cv`) ويحاول إرسال الرسالة عبر SMTP.
- إذا لم تُهيأ متغيرات SMTP، يخزن ملخص الطلب محليًا في مجلد `uploads/`.

تشغيل محلي (مطلوب Node.js):

1) انسخ المثال وقم بإنشاء `.env`:

```powershell
copy .env.sample .env
# ثم حرر .env واملأ بيانات SMTP وTO_EMAIL
```

2) ثبّت الحزم:

```powershell
npm install
```

3) شغّل الخادم:

```powershell
npm start
```

4) افتح المتصفح إلى:

http://localhost:3000/apply.html

ملاحظات:
- يجب أن تملأ `TO_EMAIL` وبيانات `SMTP_*` لإرسال البريد تلقائياً.
- الافتراضي يخزن الملفات والنصوص في `uploads/` ويُبلّغ من خلال رد JSON.
- لتحويل الاستلام إلى خدمة حقيقية، استخدم مزوّد SMTP أو API مثل SendGrid.
